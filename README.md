# Foundry VTT BS Collection

Eine Sammlung kleiner, unabhängiger Funktionen, die konkrete Probleme in Foundry VTT lösen oder spontane Ideen umsetzen. Das Modul ist für Foundry VTT 13 ausgelegt; jede Funktion bleibt in einem eigenen ES-Modul gekapselt.

## Installation

Das Repository als Ordner `foundry-vtt-bs-collection` in `Data/modules/` ablegen und das Modul in der gewünschten Welt aktivieren.

## Enthaltene Funktionen

### Emily schiebt heimlich Tokens

Wenn der Benutzer mit der ID `ZoypzwFHSgFjsV4j` ein Token verschiebt, erscheint auf diesem Benutzer-Client ein Dialog mit der Meldung „Emily schiebt schon wieder heimlich Tokens.“ und dem Button „Tut mir leid!“.
